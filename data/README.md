# EduSense Dataset Directory

This directory houses synthetic and institutional datasets used for testing, demonstration, and ML training:

* `sample/college_academic_dataset_clean.csv`: 600 realistic institutional student academic records used for ML training and 5-fold cross validation.
* `sample/college_academic_dataset_raw.csv`: Raw dataset containing 84 rows with deliberate edge cases (out-of-range attendance > 100%, negative scores, missing IDs, duplicates) used to demonstrate the Admin Data Ingestion validation engine.
* `sample/sample_students_batch.xlsx`: Excel workbook formatted student records for testing multi-format imports.
